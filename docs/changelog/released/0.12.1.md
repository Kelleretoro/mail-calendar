## Changes in this release

Engineering commentary, carried over from each fragment. Never pasted into a store.

### The Linux app is built again — `the-linux-app-is-built-again` (linux, patch)

> `AppInput::RestartAccountSetup` lost its last release caller when the setup screen's Back button
> moved to `AccountSetupBack`, which left the debug-only showcase hook as its one constructor. A
> release build compiles that hook out, so the denied `dead_code` lint stopped the compile, and
> only the tag-triggered release job builds with `--release`. The variant and its match arms now
> carry the hook's own `cfg`.
